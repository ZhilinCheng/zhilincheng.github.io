# Zhilin Cheng — portfolio website

A static portfolio for quantitative risk and derivatives roles. The site is built with plain HTML and CSS, without a build step.

## Publish with GitHub Pages

Place these files in the root of the public `zhilincheng.github.io` repository. In the repository's **Settings → Pages**, publish from the default branch's root directory. The site will appear at <https://zhilincheng.github.io/>.

## Content notes

The site describes public professional experience and selected research repositories. It omits a phone number and personal details from the career break. Project descriptions distinguish exploratory public code from professional work.
